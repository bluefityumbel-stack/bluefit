GitHub Desactivado

Usa un repositorio privado y distinto al de tus páginas. Este archivo contiene nombres, teléfonos y contactos de emergencia: en un repositorio público (por ejemplo el de GitHub Pages) lo vería cualquiera.

Cómo configurarlo (una vez)
  1. En GitHub crea un repositorio nuevo, marcado como Private (por ejemplo bluefit-datos). Marca “Add a README” para que tenga una rama.
  2. Ve a Settings (tu perfil) › Developer settings › Personal access tokens › Fine-grained tokens › Generate new token.
  3. En “Repository access” elige Only select repositories y selecciona solo ese repositorio. En Permissions › Repository permissions pon Contents: Read and write.
  4. Copia el token (solo se muestra una vez), pégalo arriba junto con tu usuario y el nombre del repositorio, y presiona “Guardar y probar”.

El token queda guardado solo en este navegador y no va en los respaldos. Si lo pierdes o vence, crea otro.

Google Sheets Desactivado

La hoja muestra Inscritos, Pagos y una pestaña por mes de asistencia, siempre actualizadas desde este sistema. Es un espejo: si editas la hoja a mano, el cambio no vuelve al sistema (y se sobrescribe en la próxima subida). No compartas esa hoja con nadie: tiene datos personales.

Cómo configurarlo (una vez)
  1. Crea una hoja de cálculo nueva en Google Sheets (por ejemplo “BlueFit Datos”).
  2. Menú Extensiones › Apps Script. Borra lo que haya y pega el código de abajo.
  3. En la primera línea cambia PON-AQUI-UNA-CLAVE-LARGA por una clave propia (letras y números, sin espacios).
  4. Implementar › Nueva implementación › Tipo: Aplicación web. “Ejecutar como”: Yo. “Quién tiene acceso”: Cualquier persona. Implementar y acepta los permisos.
  5. Copia la URL de la aplicación web (termina en /exec), pégala arriba con la clave y presiona “Guardar y probar”.
  6. Si más adelante cambias el código del script, usa Implementar › Administrar implementaciones › editar › Nueva versión.
